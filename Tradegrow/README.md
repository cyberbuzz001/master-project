# Trade GrowX Production Brokerage Simulation Platform

Production-ready multi-user brokerage simulation & paper trading platform with real-time WebSocket market data streaming, option chain analytics, and RMS validation.

---

## Live Market Data Streaming & Price Freshness Architecture

The frontend (`client/`) features a high-throughput, resilient live market data layer designed to eliminate stale prices, silent synthetic fallbacks, and unannounced tick drops.

### Core Components

1. **`MarketSocketProvider` (`hooks/useMarketSocket.ts`)**:
   - Single shared native `WebSocket` connection (`ws://<host>/ws`) with JWT token authentication.
   - Ref-counted token subscription manager: components register tokens via `useSubscribeTokens(tokens)`. Tokens are subscribed on mount and unsubscribed when all mounting components unmount.
   - Exponential backoff auto-reconnect strategy: `1s`, `2s`, `4s`, `8s`, `16s` up to `30s` cap.
   - Max reconnection limit: After 5 failed consecutive reconnect attempts, socket status transitions to `UNAVAILABLE` ("Live feed unavailable — showing last known prices").
   - Auto re-subscription: On reconnection, the manager automatically re-subscribes to all active tokens.
   - Batch rendering: High-frequency tick updates are batched per animation frame via `requestAnimationFrame` to maintain smooth 60 FPS performance without React re-render thrashing on 20+ strike option chains.

2. **`useTickFreshness` (`hooks/useTickFreshness.ts`)**:
   - Per-token price freshness state machine derived from socket status, NSE market hours, tick timestamps, and backend flags.
   - **State Machine Values**:
     - `LIVE`: Socket connected, tick received within staleness threshold (default `5000ms`), market open.
     - `STALE`: Socket connected, but no tick received within threshold (e.g. frozen feed).
     - `DISCONNECTED`: Socket offline, reconnecting, or unavailable.
     - `MARKET_CLOSED`: Outside NSE hours (09:15–15:30 IST, Mon–Fri, excluding weekends/holidays). Shows last close price without false staleness alerts.
     - `SYNTHETIC`: Backend explicitly flagged tick as fallback/mock price (`isSynthetic: true`).
   - Active 1-second evaluation timer: Continuously checks visible tokens so the UI flips state even if tick arrivals cease completely.
   - Initial Tick Timeout: Telemetry event logged if a subscribed token receives 0 ticks within 10 seconds of subscription.

3. **`PriceBadge` (`components/PriceBadge.tsx`)**:
   - Reusable indicator dot + text tag displaying state across spot tickers, option chain cells, and watchlists.

4. **`SpotPriceTicker` (`components/SpotPriceTicker.tsx`)**:
   - High-priority spot index ticker (`NSE_NIFTY50`, `BSE_SENSEX`, `NSE_BANKNIFTY`, etc.).
   - Visual sub-second price pulse animations (`flash-up` green, `flash-down` red) on tick updates.

5. **Option Chain Integration (`components/OptionChainView.tsx`)**:
   - **ATM Recalculation Safeguard**: ATM strike recalculation is dynamically tied to live spot price state. If spot price is `STALE` or `DISCONNECTED`, ATM recalculation is frozen and an alert banner is displayed ("ATM calculation paused — spot feed stale/offline").
   - **Token Mapping Gap Detection**: If a strike token has received 0 ticks since subscription, LTP cell displays `—` with a "No live tick received (Token mapping pending)" tooltip instead of `0` or a fake price.

6. **Market Telemetry (`hooks/useMarketTelemetry.ts`)**:
   - Non-blocking client-side telemetry logger recording WebSocket reconnects, staleness state changes, and initial tick timeout gaps.

## Backend Payload Specification

To enable complete freshness tracking and synthetic detection on the frontend, the backend WebSocket `MARKET_TICK` frames should conform to:

```json
{
  "type": "MARKET_TICK",
  "data": {
    "instrumentToken": "NSE_NIFTY50",
    "symbol": "NIFTY",
    "ltp": 24500.50,
    "change": 12.30,
    "changePercent": 0.05,
    "timestamp": 1754563963000,
    "isSynthetic": false
  }
}
```

- **`timestamp`** *(number)*: Millisecond Unix epoch timestamp when the tick was generated by the market feed.
- **`isSynthetic`** *(boolean, optional)*: Explicit flag set to `true` if the server is delivering fallback or simulated mock ticks.
