# Security

- Encrypt/tokenize sensitive identifiers.
- Never store broker API secrets in database plaintext.
- Use least-privilege DB roles.
- Use RLS for client data isolation.
- Use immutable audit and ledger records.
- Use KMS/secret manager for credentials.
- Rotate secrets and database credentials.
- Enable TLS in production.
- Add PITR backups and tested restore procedures.
- Apply retention policies appropriate to jurisdiction and business obligations.
